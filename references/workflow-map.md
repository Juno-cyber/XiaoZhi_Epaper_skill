# Cron 可视化与对话交付

`scripts/workflow_map.py` 把小智定时任务、近期执行和设备状态合成一张自包含 SVG。它的首要出口是对话：任务设计完成后，用户应当在同一条回复里直接看到结果，而不必自己寻找文件。

SVG 与 Litsea_Top 使用同一视觉语言：白底、黑灰文字、细边框、近直角卡片，品牌红 `#FF5A5A` 只用于触发点、失败和风险。不同任务不再分配不同颜色，也不绘制墨水屏页面或元素预览。

## 两种使用时机

### 尚未创建：候选预览

用户只是在设计方案时，不得为了生成图片而写入调度器。使用 `--preview-*` 加入一个仅存在于快照中的候选任务：

```bash
python3 scripts/workflow_map.py --discover \
  --preview-name "工作日提醒" \
  --preview-schedule "0 8 * * MON-FRI" \
  --preview-page 7
```

图中会明确显示“预览，尚未创建”。三个必填参数必须同时提供；页码限 6–15，调度必须是有效的五段 cron。

### 已确认创建或修改：正式视图

调度器确认成功后运行：

```bash
python3 scripts/workflow_map.py --discover
```

创建、更新、暂停、恢复、删除后都应重新生成。不要在每次 cron 执行时刷新总览图。

## 对话中的交付顺序

1. 客户端支持本地图片时，用绝对路径直接嵌入 SVG。
2. 支持文件附件但不支持内嵌时，附上 SVG。
3. 仅当渠道拒绝 SVG 且环境已有转换器时，额外转换 PNG。
4. 两种图像能力都没有时，给出绝对路径和简短的任务/状态/风险摘要，并明确说明当前只能文本交付。

默认产物：

- `~/.hermes/xiaozhi_canvas/workflow-map.svg`：给人查看的自包含图片。
- `~/.hermes/xiaozhi_canvas/workflow-map.json`：版本化、脱敏、供 Hermes 后续处理的机器可读快照。

命令末尾还会输出 `ARTIFACT_SVG=<绝对路径>` 和 `ARTIFACT_JSON=<绝对路径>`，便于 Agent 稳定提取产物位置。

## 稳定的目标元数据

新建任务应在 prompt 首行写入：

```text
[XIAOZHI_CRON_META v1 page=6 mode=canvas-refresh]
```

页码只允许 6–15；mode 是最多 32 字符的小写字母、数字和连字符。该标记只帮助可视化识别目标，不授予任何设备权限。旧任务仍会根据任务名和 prompt 推断，图中以 `?` 标示低置信度，避免把猜测伪装成事实。

## 图中包含什么

- 摘要卡：任务数、启用数、风险数和设备连接状态。
- 任务表：名称、调度、目标页面和当前状态。
- 24 小时时间轴：所有任务统一使用品牌红触发点，高频任务采用有上限的抽样。
- 脱敏 JSON 仍保存最多 64 条画布历史和每任务最多 5 次执行状态；SVG 仅显示最近刷新时间，不展开历史内容。
- 风险提示：设备离线或部分读取失败、目标推断、无效调度、连续失败、多个任务争用同一页面、执行数据库不可读等。

默认只显示小智相关任务；诊断时可用 `--include-all-jobs`。设备发现是尽力而为，设备离线时仍生成任务视图并清楚标记离线。需要把设备不可达视为失败时使用 `--strict-device`。

## 数据与隐私边界

读取来源包括 `~/.hermes/cron/jobs.json`、`~/.hermes/cron/executions.db`、`~/.hermes/xiaozhi_canvas/history.jsonl` 和局域网设备健康状态。生成器不再读取页面元素，因此设备页面文字与图片不会进入 SVG。

JSON 快照不包含原始 prompt、脚本、工作目录、聊天来源标识或执行错误正文。名称和屏幕文字有长度上限，元素坐标会按 296×128 边界过滤，所有 SVG 文本统一 XML 转义。输入大小、任务数、历史数、执行数和设备元素数均有硬上限，避免异常数据导致失控的内存或渲染开销。

SVG 与 JSON 采用同目录临时文件后原子替换，并拒绝符号链接目标。SQLite 以只读模式打开；可视化本身不会修改 cron、执行数据库或设备页面。

## 架构边界

cron 注册表和执行记录由 Hermes 维护，不存储在小智设备中。小智设备只接收定时触发后的页面或元素更新。因此 SVG/JSON 是 Hermes 本地产物，应由 Agent 在对话中交付，不应伪装成设备能力。

Litsea_Top 是面向小智设备的静态控制网站，正常部署时无法访问用户机器上的 Hermes 运行时文件。即使本机开发代理能够临时读取 SVG，也不应把这种联调便利设计成正式的“定时任务”网页功能。
